# GLAMOURSPHAIR Luxury — UI/UX Refinement Pack

This pack is for a careful, conversion-focused refinement of:
https://www.glamoursphairluxury.com/

The current GLAMOURSPHAIR brand identity is the baseline. The goal is not to redesign the store into a different luxury aesthetic, but to improve anything that may quietly reduce trust, product discovery, add-to-cart confidence, checkout completion, mobile usability, accessibility, performance, SEO, repeat visits, or perceived quality.

## Installation
Do not overwrite the existing project README.

If the repository already has a root `AGENTS.md`, merge `AGENTS_UI_ADDENDUM.md` into it instead of replacing it.

Recommended structure:
```text
AGENTS.md
DESIGN.md
CODEX_GLAMOURSPHAIR_REFINEMENT_PROMPT.md
.agents/skills/glamoursphair-ui/SKILL.md
docs/ui/
```

## Core principle
**Preserve the luxury identity; remove friction.**

Do not invent reviews, ratings, delivery promises, product attributes, stock levels, urgency, testimonials, certifications, awards, or payment methods.
