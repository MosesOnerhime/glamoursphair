# Product Detail Standards

Premium/high-consideration hair products benefit from a clear PDP.

## Above the fold
Expose:
- image/gallery;
- name;
- price;
- sale price where real;
- availability/status;
- essential options;
- Add to Cart;
- WhatsApp help;
- concise delivery/payment confidence.

## Gallery
Use real views where available:
- front;
- side;
- back;
- hairline/lace close-up;
- texture;
- full length;
- worn view;
- video/movement.

## Specifications
Show only verified fields such as:
- length;
- weight/density;
- lace/fitting dimensions;
- lace type;
- hair origin/type;
- color;
- texture;
- glueless/ready-to-wear status.

## Price
Current price dominant; old price secondary/struck when genuinely discounted.

## Availability
Use actual operational states only.

## Add to Cart
Preserve exact product/variant and show clear success feedback.

## WhatsApp
Prefill product name, URL, and selected variant where relevant.

## Delivery / returns / care
Make verified information discoverable before purchase. Never invent delivery times or return guarantees.

## Related products
Use same collection, similar length/price, or complementary care — not random filler.

## Structured data
Use accurate Product/Offer schema when appropriate. Never fabricate ratings or reviews.
