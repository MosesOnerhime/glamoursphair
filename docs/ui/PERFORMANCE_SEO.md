# Performance and SEO Standards

## Core Web Vitals
Target:
- LCP <= 2.5 s
- INP <= 200 ms
- CLS <= 0.1

## Images
The current catalog is image-heavy. Use responsive sizes, modern formats, lazy loading below the fold, reserved dimensions, and realistic source sizes. Do not priority-load the whole product grid.

## PDP gallery
Load the main product image promptly; secondary/zoom images progressively.

## INP
Audit search, filtering, Add to Cart, cart drawer, quantity changes, currency estimates, and location selection.

## JavaScript
Do not add a large carousel, animation library, or UI framework for minor polish.

## Product SEO
Important products should have unique:
- title;
- meta description;
- canonical;
- Open Graph;
- product imagery;
- structured data.

Example title:
`Wig Kelly in HD Lace | GLAMOURSPHAIR Luxury`

## Product/Offer structured data
Where accurate, include name, image, description, price, priceCurrency, availability, URL, shipping, and return information.

Never fabricate reviews/ratings.

## Collection URLs
If collection pages are crawlable, use unique metadata and canonical URLs. If the current site is mostly a one-page filtered catalog, do not create indexable faceted URL explosions without an SEO plan.

## Canonicals
Use the real production domain, not preview/deployment URLs.

## Social previews
Product pages should share well on WhatsApp/social with meaningful product imagery and concise metadata.

## Local business
Only add verified studio/contact information. Never invent coordinates, ratings, or profiles.
